# Мини-приложения Telegram для бизнеса (демо)

Витрина примеров: клиент проходит сценарий и сразу видит, какое сообщение получит владелец бизнеса.
Все приложения работают в демо-режиме: данные никуда не отправляются.

| Папка | Что показывает |
|---|---|
| `salon/` | Онлайн-запись в салон: специалист, услуги, дата и время |
| `manicure/` | Запись на маникюр |
| `flowers/` | Заказ цветов: каталог, корзина, доставка |
| `auto/` | Запись в автосервис |
| `lead/` | Приём заявок на подбор недвижимости |
| `shared/` | Общие стили и функции для всех приложений |

Приложение «Учёт денег» лежит в отдельном репозитории `money-mini-app`.
